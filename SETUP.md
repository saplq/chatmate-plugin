# Set up ChatMate

1. Install or enable the ChatMate plugin/connector in ChatGPT Work, Codex, Claude Code, or Claude Cowork.
2. In your personal ChatMate Telegram bot, choose the provider and tap **Open / install ChatMate**.
3. Start the connector OAuth flow in the provider.
4. Copy the one-time code from Telegram and enter it only in the ChatMate OAuth pairing form. Do not paste it into a chat or prompt.
5. Ask the provider to check ChatMate. A successful authorized tool call verifies the connection.
6. Return to Telegram and tap **Check connection**.

The MCP is remote at `https://chatmate-plum.vercel.app/api/mcp`; nothing is installed on your server or phone.
